# Custom Object Pooling System Using Zenject  

A Unity package that provides a flexible and efficient **object pooling system** powered by **Zenject**.  
This system helps optimize performance by reusing objects instead of instantiating and destroying them repeatedly.  

---

##  Features  
-  Efficient memory management through pooling.  
-  Seamless integration with **Zenject** dependency injection.  
-  Modular and extendable design for different game objects.  

---

##  Installation  

1. Clone or download this repository.  
2. Add the package to your Unity project.
3. Ensure **Zenject** is installed in your project.  

---

##  Usage  

1. Create a pool installer using Zenject.  
2. Bind your prefab(s) to the pool.  
3. Request objects from the pool instead of instantiating directly.
